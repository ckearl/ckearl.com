# Logo sources

All logos are trademarks of their teams. These are for a private page.

- Default for every team: ESPN's public team API.
- NHL retro logos: NHL records logo API (`records.nhl.com/site/api/logo`), using the
  longest era ending between 1985 and 2006. Teams with no match keep the default.
- MLB retro logos: github.com/iamnewton/mlb-logos (repo licensed MIT), using the latest
  logo from 1995 or earlier. Guardians keep the default.
- NBA retro logos: github.com/TGOlson/nba-logos, using 1996 (no license stated, scraped
  from basketball-reference). Moved franchises use their 1990s identity: Sonics for the
  Thunder, Bullets for the Wizards, Vancouver for Memphis, New Jersey for Brooklyn.
- Utah Jazz (1980-1996), and hand-picked NFL and European club logos: Wikimedia Commons.
